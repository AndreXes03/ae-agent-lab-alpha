# Working rules for agents in this repository

Read [README.md](README.md) for the public alpha's scope and supported demo path. Follow the user's brief and preserve its creative direction.

Before any After Effects mutation, identify the target application instance, inspect the active project, and work only on an expendable fixture or a copied project. Preserve unsaved user work. Save a variant before editing. After a timeout, inspect state before retrying because the call may already have executed.

Keep arbitrary ExtendScript disabled unless a typed operation cannot perform the task and the specific use is reviewed. Render representative frames and inspect the actual images before claiming visual success. Never infer a completed render from a queued or processing state.

Do not call a test native acceptance if it ran only against mocks. Record the AE version, input project, output project, rendered paths, and observed errors for live tests. Retain the inherited MIT notices in derivatives.

For edits to existing projects, follow [docs/AGENT-WORKFLOW.md](docs/AGENT-WORKFLOW.md). Verify the actual delivery composition, not only isolated review comps. Use [docs/MOTION-QUALITY.md](docs/MOTION-QUALITY.md) for offline planning and read-only camera checks.
